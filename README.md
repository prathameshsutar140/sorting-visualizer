# 📊 AlgoViz — Sorting Algorithm Visualizer

AlgoViz is an interactive web-based educational tool designed to help developers and students understand how sorting algorithms are actually implemented and executed under the hood. By combining a modern TypeScript frontend with high-performance C programming logic, it bridges the gap between web interfaces and low-level system execution.

---

## ✨ Features

- **🎨 Actual Sorting Interface:** Visualizes real-time swaps, comparisons, and array transformations.
- **⚡ TypeScript & Modern Web Frontend:** Clean, type-safe frontend code managing DOM updates and user controls.
- **⚙️ C Programming / WebAssembly Integration:** Designed to leverage high-performance C algorithms for core data processing.
- **🔧 Modular Architecture:** Separated into multiple files (`index.html`, `style.css`, `app.ts`) for clean project organization in VS Code.
